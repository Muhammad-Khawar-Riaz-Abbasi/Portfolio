## Featured project

### SecureScope

A privacy-first password security auditor built with Python, FastAPI, React, TypeScript, and Docker. SecureScope provides explainable password risk scoring and k-anonymity breach checks without attempting logins, storing credentials, or scraping social accounts.

- **Repository:** [github.com/Muhammad-Khawar-Riaz-Abbasi/securescope](https://github.com/Muhammad-Khawar-Riaz-Abbasi/securescope)
- **Engineering focus:** privacy by design, typed APIs, defensive security, automated testing, CI/CD, and accessible UX
- **Architecture:** FastAPI service + React/Vite client + Docker Compose + GitHub Actions
